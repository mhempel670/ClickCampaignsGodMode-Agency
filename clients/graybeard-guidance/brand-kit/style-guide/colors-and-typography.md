# Graybeard Guidance — Style Guide (v2)

## Colors

| Name | Hex | Use |
|------|-----|-----|
| Charcoal | #2B2B2B | Backgrounds, headers |
| Black | #121212 | Text, high-contrast |
| Yellow Gold | #D4A017 | Primary CTA, highlights |
| Brick Red / Maroon | #8C2F26 | Secondary CTA, emphasis |
| Warm White | #F7F5F0 | Body backgrounds |
| Pure White | #FFFFFF | Contrast, cards |

**Allocation:** charcoal/black ~50%, white ~30%, gold ~12%, brick ~8%. Never put gold and brick on the same element.

## Typography

- **Headings:** Roboto Slab (primary), Spectral or Tiempos as alternates
- **Body:** Source Sans Pro (primary), Lato or Open Sans as alternates

## Google Fonts import

```html
<link href="https://fonts.googleapis.com/css2?family=Roboto+Slab:wght@600;700&family=Source+Sans+3:wght@400;600;700&display=swap" rel="stylesheet">
```
