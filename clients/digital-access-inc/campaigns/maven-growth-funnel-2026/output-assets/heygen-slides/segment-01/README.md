# Segment 1 slides — export to PNG for HeyGen

HeyGen does **not** create slides from the voice script. These HTML files **are** your slides.

## Export each slide as PNG (1920×1080)

1. Double-click `seg01-slide01.html` (opens in Chrome/Edge).
2. Zoom so the slide fills the window, or use DevTools device mode at 1920×1080.
3. **Windows:** `Win + Shift + S` → capture full slide → save as `seg01-slide01.png`
4. Repeat for `seg01-slide02.html` through `seg01-slide06.html`.

**Tip:** In Chrome, press `F12` → toggle device toolbar → set dimensions **1920 × 1080** → screenshot.

## Then in HeyGen

|-------|-----------------|------------------|
| 1 | seg01-slide01.png | segment-01-hook.txt → SCENE 1 |
| 2 | seg01-slide02.png | SCENE 2 |
| 3 | seg01-slide03.png | SCENE 3 |
