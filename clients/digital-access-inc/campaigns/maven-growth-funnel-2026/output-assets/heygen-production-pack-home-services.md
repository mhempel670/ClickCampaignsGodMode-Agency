## How HeyGen fits (simple)

| You build | Tool |
|-----------|------|
| Slide images (PNG) | Google Slides or PowerPoint |
| Talking-head video | HeyGen — **1 project per segment** (6 projects) |
| Screen demo | Growbotik recording + voice in CapCut |
| Final movie | CapCut or Descript — stitch Segments 1–6 + demo |

**HeyGen does NOT auto-build slides.** You upload each slide PNG as the **background** for each **Scene**.

---

## HeyGen scenes: how many per segment?

- HeyGen allows **many scenes** in one video, but each scene = one generate/wait cycle.
- **Sweet spot: 4–7 scenes per segment** (one HeyGen project per segment).
- This pack uses **33 slides** total and **33 HeyGen scenes** (1 scene = 1 slide = 1 paste block).  
  - Segment 2 is the longest (11 scenes). Budget extra time there.
- If a scene fails or sounds wrong, you only re-render **that scene**, not the whole segment.

## Slide design (all segments)

- Background: `#0F172A` (dark navy)
- Headline text: white, bold, large
- Stats / emphasis: `#10B981` (emerald)
- Body: white or `#94A3B8` gray, minimal bullets
- Export: **1920×1080 PNG**, one file per slide  
- Filename: `seg01-slide01.png`, `seg02-slide03.png`, etc.

---

## HeyGen settings (every project)

1. **Create** → **Avatar video** (or **Video** with avatar).
2. Avatar: bottom-right, ~20% width.
3. Voice: your **cloned voice**.
4. For each **Scene**: upload matching slide PNG → paste voice text from `heygen-voice-paste/` → Generate.
5. When all scenes in a segment are done → **Export 1080p** → save as `seg01-hook.mp4`, etc.

Replace `[NAME]` in Segment 6 with your name before pasting.
